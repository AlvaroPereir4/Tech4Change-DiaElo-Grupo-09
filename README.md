# LightPulse

**Dados que viram cuidado, não diagnóstico.**

Plataforma que lê dados de smartwatches acessíveis — frequência
cardíaca, variabilidade e movimento — e os transforma em observações
compreensíveis sobre a rotina de crianças autistas.

Não detecta crises, não diagnostica emoções e não substitui profissionais.
Mostra padrões para que a família converse e decida melhor.
